# Emotion Recognition from Speech

## Objective

Recognize human emotions from speech audio recordings using deep learning.

## Dataset

RAVDESS Emotional Speech Dataset

## Technologies Used

* Python
* Google Colab
* Librosa
* TensorFlow
* NumPy
* Pandas

## Features

* MFCC Feature Extraction
* Audio Signal Processing
* Deep Learning Classification
* Emotion Prediction

## Emotions Classified

* Happy
* Sad
* Angry
* Fearful
* Neutral
* Calm
* Disgust
* Surprised

## Results

Successfully trained a neural network model to classify emotions from speech audio data.
